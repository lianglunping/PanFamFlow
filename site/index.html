Target Pan-Gene-Family Analysis

目标泛基因家族分析流程

PanFamFlow 分析目标基因家族；它不是泛基因组组装流程，也不构建 graph pangenome。

从成员鉴定、家族系统发育和 OrthoFinder HOG，到目标家族 Core / Soft-core / Shell / Cloud 分类、结构、定位、复制与共线性、Ka/Ks、启动子和表达整合。

快速开始

安装

git clone https://github.com/lianglunping/PanFamFlow.git
cd PanFamFlow
mamba env create -f environment.yaml
uv sync --locked --dev

一个配置入口

日常分析由 config.yaml 控制。先校验和查看执行计划，再启动工作流。

uv run panfamflow validate -c config.yaml
uv run panfamflow plan -c config.yaml
uv run panfamflow run -c config.yaml

查看 config.yaml 模板

Smart resume / 断点接续

Snakemake 负责增量执行；PanFamFlow 记录配置与执行指纹，使用原子输出、失败重试及模块级恢复。修正输入、参数、软件环境或资源问题后，可直接重跑原命令，完整且仍有效的结果会跳过。

uv run panfamflow status -c config.yaml
uv run panfamflow resume -c config.yaml
